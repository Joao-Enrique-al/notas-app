# 📝 Notas App

Um aplicativo de notas criado para resolver um problema simples: **eu queria fazer minhas anotações sem precisar pagar por um aplicativo.** 😂

Em vez de procurar outra alternativa, decidi colocar a mão na massa e desenvolver minha própria solução.

Este projeto é um experimento pessoal para praticar desenvolvimento mobile, explorar novas tecnologias e criar uma ferramenta que realmente faça sentido para o meu dia a dia.

## 🎯 Objetivo

Criar um aplicativo de notas próprio, unindo aprendizado em programação e utilidade no cotidiano. Afinal, às vezes, a melhor maneira de resolver um problema é construir a sua própria solução.

## 🛠️ Tecnologias

- **React Native** — desenvolvimento de interfaces mobile.
- **Expo** — ambiente e ferramentas para desenvolver e executar a aplicação.
- **JavaScript / TypeScript** — conforme utilizado no projeto.

## 🚀 Como executar o projeto

### Pré-requisitos

- [Node.js](https://nodejs.org/)
- npm
- [Expo Go](https://expo.dev/go) ou um emulador compatível, conforme a configuração do projeto.

### Instalação

Clone o repositório:

```bash
git clone https://github.com/Joao-Enrique-al/notas-app.git
```

Entre na pasta do projeto:

```bash
cd notas-app
```

Instale as dependências:

```bash
npm install
```

Inicie o Expo:

```bash
npx expo start
```

Siga as instruções exibidas no terminal para executar o aplicativo no ambiente compatível com a configuração atual do projeto.
